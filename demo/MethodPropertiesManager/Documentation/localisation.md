# メソッドプロパティマネージャーのローカライズ

## 実行

シングルユーザー版4Dでプロジェクトを開き、インタープリターモードで
`open_property_manager`を実行します。コンポーネントとして使用する場合も、
ホストプロジェクトから同じ公開メソッドを呼び出します。

このメソッドは処理をブロックしないウィンドウを開きます。再実行すると、
新しいウィンドウを追加せず、既存のウィンドウを前面に表示します。
自動起動は追加せず、ホストのメニューバーも変更しません。
「閉じる」はフォームを閉じる操作であり、4Dを終了する操作ではありません。

## 翻訳リソース

`Resources/en.lproj/`と`Resources/ja.lproj/`に英語・日本語のXLIFFがあります。
`methodProperties*.xlf`はフォームと選択肢、`messages*.xlf`は実行条件に関する
警告メッセージです。フォームの「閉じる」には4D標準の`CommonClose`を使用します。

開発時にプロジェクトの日本語リソースを選択する場合は、次のコードを実行してから
フォームを開きます。

```4d
SET DATABASE LOCALIZATION("ja"; *)
open_property_manager
```

英語に戻す場合は`"ja"`を`"en"`に変更します。
プリエンプティブ実行の選択肢を含め、表示するラベルだけを翻訳しています。
`MPM_choices`の`keys`、メソッド名、保存する属性名・属性値は変更しないでください。
日本語の編集説明には改行が必要なため、XLIFFで`&#13;`を使用しています。

プロジェクトの互換バージョンは元の4D 20.3のままです。
`MPM_text`の`Localized string:C991`は、4D自身が生成したコマンドトークンを使用し、
コマンド名の変更前後で同じリソース取得コマンドを参照します。

## 開発時の確認

リポジトリルートから、既存のランナーで英語・日本語のリソースとフィルターを確認できます。
`TOOL4D`には使用するtool4dの実行ファイルを指定します。

```sh
python tools/tool4d.py demo/MethodPropertiesManager tools/tests/demo_localisation.4dm
python tools/tool4d.py demo/MethodPropertiesManager --compile
```

このランナーは一時コピーを使用するため、元のプロジェクトやデータは変更しません。
画面はGUI版4Dで別途確認してください。特に、選択肢の文字切れ、
「適用」「解除」とプリエンプティブ実行用の3ボタンの切り替え、
複数選択、属性の変更、ウィンドウの再利用を確認します。
